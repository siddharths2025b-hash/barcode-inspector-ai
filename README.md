# barcode-inspector-ai
AI-assisted label noise detection for industrial barcode images.
Barcode Inspector AI

Team: NADAN CODERS

Problem Statement

Incorrect labels in industrial barcode image datasets can reduce the reliability of machine learning models. Manual inspection of large datasets can also be time-consuming.

Proposed Solution

Barcode Inspector AI is a dashboard for exploring label noise detection in industrial barcode datasets. It presents an approach combining confident learning, loss-based outlier detection, and cross-validation disagreement to identify suspicious labels for review.
